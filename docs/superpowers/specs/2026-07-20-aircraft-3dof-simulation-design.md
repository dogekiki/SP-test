设计并实现一个**飞行器三自由度仿真程序**,用于教学演示,聚焦导弹/火箭的纵向质点弹道仿真,支持三维轨迹可视化与关键飞行指标分析。

## 2. 架构设计

### 2.1 模块化脚本架构

采用模块化脚本架构,数据通过 `cfg` 结构体和状态向量 `x` 传递,接口清晰,适合教学。

### 2.2 目录结构

```
trajectory_3dof/
├── main.m              # 主脚本:编排初始化→积分→可视化流程
├── config.m            # 返回 cfg 结构体(飞行器参数/大气/积分选项)
├── dynamics.m          # 状态导数函数 [xdot] = dynamics(t, x, cfg)
├── aerodynamics.m      # 气动计算 [F_aero] = aerodynamics(x, cfg)
├── atmosphere.m        # 标准大气模型 [rho, a, T] = atmosphere(h)
├── visualize.m         # 三维轨迹 + 曲线绘制
├── postprocess.m       # 数据导出与指标统计
└── tests/              # 测试脚本
    ├── test_dynamics.m
    ├── test_atmosphere.m
    ├── test_energy_conservation.m
    └── test_baseline.m
```

### 2.3 模块职责

- **main.m**: 主入口,编排 `config → dynamics → ode45 → visualize/postprocess` 流程
- **config.m**: 集中管理所有参数,返回 `cfg` 结构体
- **dynamics.m**: 核心动力学,计算状态导数 `xdot`
- **aerodynamics.m**: 气动力计算,返回阻力/升力
- **atmosphere.m**: ISA 标准大气模型
- **visualize.m**: 三维轨迹动态绘制 + 状态曲线
- **postprocess.m**: 射程、最大高度、飞行时间等指标统计

## 3. 组件设计

### 3.1 飞行器模型(cfg)

| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 质量 | $m$ | kg | 起飞质量(含燃料) |
| 参考面积 | $S$ | m² | 气动参考面积 |
| 推力 | $P(t)$ | N | 主动段恒定,耗尽后为0 |
| 阻力系数 | $C_{D0}$ | - | 零升阻力系数 |
| 诱导阻力因子 | $K$ | - | $C_D = C_{D0} + K C_L^2$ |
| 升力系数导数 | $C_{L\alpha}$ | 1/rad | 升力对攻角导数 |
| 燃料质量 | $m_{fuel}$ | kg | 主动段消耗 |
| 比冲等效时间 | $t_{burn}$ | s | 推力持续时间 |

### 3.2 状态向量

$$\mathbf{x} = [x, y, h, V, \gamma, \psi]^T$$

- $x, y$: 水平位置(m)
- $h$: 高度(m)
- $V$: 速度大小(m/s)
- $\gamma$: 航迹角(rad)
- $\psi$: 航向角(rad,纵向简化时恒定)

### 3.3 核心组件

1. **动力学模块**: 质点纵向运动方程,含推力、重力、阻力
2. **大气模块**: ISA 标准大气,密度 $\rho(h)$、声速 $a(h)$、温度 $T(h)$
3. **积分器**: ode45,事件函数检测落地($h=0$)
4. **可视化模块**: comet3 动态轨迹 + subplot 曲线(高度/速度/航迹角/马赫数)
5. **后处理**: 射程、最大高度、飞行时间、马赫数曲线

## 4. 数据流与方程

### 4.1 状态方程(质点纵向三自由度)

$$\dot{x} = V \cos\gamma \cos\psi$$

$$\dot{y} = V \cos\gamma \sin\psi$$

$$\dot{h} = V \sin\gamma$$

$$\dot{V} = \frac{P \cos\alpha - D - m g \sin\gamma}{m}$$

$$\dot{\gamma} = \frac{P \sin\alpha + L - m g \cos\gamma}{m V}$$

$$\dot{\psi} = 0 \quad (\text{纵向简化,无侧滑})$$

### 4.2 气动力模型(中保真)

$$D = \frac{1}{2} \rho V^2 S C_D, \quad L = \frac{1}{2} \rho V^2 S C_L$$

$$C_D = C_{D0} + K C_L^2$$

$$C_L = C_{L\alpha} \cdot \alpha$$

其中 $\alpha$ 为攻角指令(教学场景可设为常值或简单程序)。

### 4.3 推力模型

$$P(t) = \begin{cases} P_0 & t \leq t_{burn} \\ 0 & t > t_{burn} \end{cases}$$

主动段质量变化:

$$\dot{m} = -\frac{P_0}{I_{sp} g_0} \quad (t \leq t_{burn})$$

### 4.4 数据流

```
config.m → dynamics.m → ode45 → 状态历史 → visualize.m / postprocess.m
              ↑
        aerodynamics.m + atmosphere.m
```

## 5. 错误处理与边界

1. **大气模块**: $h < 0$ 返回海平面值;$h > 86$ km 给警告并截断
2. **动力学**: $V < 1$ m/s 时 $\gamma$ 方程奇异,用小量 $\epsilon = 1$ m/s 保护
3. **积分器**: ode45 事件函数检测 $h \leq 0$ 终止,避免负高度
4. **参数校验**: `config.m` 中 `assert` 质量/面积为正
5. **马赫数限制**: $Ma > 5$ 时气动系数外推给警告
6. **数值发散检测**: 若 $V$ 或 $h$ 出现 NaN,终止并报错

## 6. 测试与验证

### 6.1 单元测试

- `test_dynamics.m`: 用解析解对照(无气动真空抛体)
- `test_atmosphere.m`: 海平面值对照标准值

### 6.2 守恒律验证

- **能量守恒**: 无推力+无阻力时,$E = mgh + \frac{1}{2}mV^2$ 守恒
- **量纲检查**: 所有方程量纲一致(N, kg, m, s)

### 6.3 基准算例

- 45° 仰角真空弹道,对照解析解射程:

$$R = \frac{V_0^2 \sin(2\theta)}{g}$$

- 主动段验证: 推力曲线积分 = 速度增量(齐奥尔科夫斯基近似)

### 6.4 可视化验证

- 轨迹连续无跳变
- 曲线标注清晰(坐标轴、图例、单位)

### 6.5 回归测试

每次修改后运行基准算例,对比关键指标(射程、最大高度、飞行时间)。

## 7. 设计决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 架构 | 模块化脚本 | 平衡清晰与扩展,适合教学 |
| 动力学 | 质点纵向 + 推力 | 完整主动段,教学价值高 |
| 可视化 | plot3 + comet | 简单,教学友好 |
| 积分器 | ode45 | MATLAB 内置,精度高 |
| 气动 | 中保真 | 概念设计足够,数据需求低 |
